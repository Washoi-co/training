# 「忘却曲線を活用する」の保存先（Googleスプレッドシート）の設定

単語トレーニングで「忘却曲線を活用する」を押した人の **ID（ニックネーム＋4ケタの番号）と学習の記録だけ** を、
A-PUSH の Google スプレッドシートに保存します。メールアドレスや本名は受け取りません。

## 手順（A-PUSH の Google アカウントで、5分くらい）
1. Google ドライブで **新しいスプレッドシート** を作る（名前の例：「A-PUSH 単語トレーニング 記録」）
2. メニューの **［拡張機能］→［Apps Script］** を開く
3. 最初から入っている `function myFunction() {…}` を全部消して、このフォルダの **`Code.gs` の中身を丸ごと貼り付け**、保存（💾）
4. 右上の **［デプロイ］→［新しいデプロイ］**
   - 歯車 ⚙ →「**ウェブアプリ**」を選ぶ
   - 説明：「単語トレーニング」（なんでもよい）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. **［デプロイ］** → 「アクセスを承認」→ アカウントを選ぶ →（「Google はこのアプリを確認していません」と出たら）［詳細］→［（プロジェクト名）に移動］→［許可］
6. 表示された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/……/exec`）をコピーして、Claude に送る

→ Claude が `words/index.html` の `SYNC_URL` にその URL を入れて公開します。

## スプレッドシートで見られること
シート「records」に、1人1行で次が入ります。
| ID | ニックネーム | 作成日時 | 最終更新 | 覚えた単語 | 習得 | コース | データ（JSON） |

## 注意
- 「アクセスできるユーザー：全員」は、**URL を知っている人がこのプログラムを呼び出せる** という意味です。スプレッドシートそのものは、共有しない限り A-PUSH 以外は見られません。
- `Code.gs` を直したときは、［デプロイ］→［デプロイを管理］→ ✏️ →「バージョン：新バージョン」で更新してください（URL は変わりません）。
